# روك سفاري - رحلات السفاري في شرم الشيخ

موقع تعريفي بصفحة واحدة (One Page) لشركة روك سفاري لرحلات السفاري في شرم الشيخ.

## المحتويات
- `index.html` — صفحة الموقع كاملة (HTML + CSS + JS في ملف واحد).

## طريقة النشر على GitHub Pages
1. ارفع محتويات هذا المجلد إلى مستودع (Repository) جديد على GitHub.
2. من إعدادات المستودع (Settings) اذهب إلى قسم **Pages**.
3. اختر Branch: `main` والمجلد `/ (root)` ثم اضغط **Save**.
4. بعد دقيقة أو دقيقتين، هيظهر لينك الموقع في نفس الصفحة بالشكل:
   `https://<username>.github.io/<repo-name>/`
